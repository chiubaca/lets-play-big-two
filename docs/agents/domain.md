# Domain docs

This is a single-context repo. Read root `CONTEXT.md` for domain language and relevant ADRs under `docs/adr/` before working in an area. If the ADR directory does not exist, proceed silently; create it only when a real decision needs an ADR.

Use the glossary's terms in tickets, plans, and code discussions. If a proposed design contradicts an ADR, call out the conflict rather than silently overriding it.
